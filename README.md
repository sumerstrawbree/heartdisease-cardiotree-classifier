# Project 
- Shows the dataframe after being label encoded and one hot encoded.
- Uses at least two parameters when in creating a Decision Tree.
- Prints the training accuracy score, testing accuracy score, and confusion matrix.
- Prints how a Decision Tree can be applied to a different field, and 2-3 factors to be wary of.
- Prints a text representation of your Decision Tree through the console.
